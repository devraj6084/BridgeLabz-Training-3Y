Core Principles of Responsive Design

Fluid Layouts

Elements resize proportionally instead of using fixed pixel widths.

width: 100%; max-width: 800px;

Flexible Media

Images and videos scale within their containers automatically.

img { max-width: 100%; height: auto; }

Breakpoints

Layout rules change at defined screen widths using media queries.

@media (max-width: 600px) { ... }
